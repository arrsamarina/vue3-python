# Task Manager Frontend

Vue 3 приложение для управления задачами.

## Разработка

```bash
npm install
npm run dev
```

Приложение будет доступно на http://localhost:3000

## Сборка

```bash
npm run build
```

## Структура проекта

- `src/components/` - Vue компоненты
- `src/views/` - Страницы приложения
- `src/router/` - Конфигурация маршрутизации
- `src/services/` - API сервисы
